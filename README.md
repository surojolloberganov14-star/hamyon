# Surojbek hamyoni

Shaxsiy pul hisobi uchun telefon ilovasi: naqd va karta qoldig'i, qarzlar va kreditlar, oylik byudjet, olinadigan pullar.

- iPhone'da Safari orqali oching va «Поделиться» → «На экран «Домой»» bilan bosh ekranga qo'shing.
- Ilova internetsiz ishlaydi.
- Ma'lumotlar faqat telefonning o'zida saqlanadi, bu repozitoriyada hech qanday shaxsiy ma'lumot yo'q.
- Zaxira: «Tarix» bo'limining oxiridagi «Zaxira olish» tugmasi.
